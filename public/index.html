ML Recommendations

Use − for not interested, → for next read, and + to like. Refresh shows a loading state while new picks are generated.

ML score is a relative match rating from 0% to 100% within your current recommendation list. The top pick is always 100%; lower picks show how they compare to that best match.

Scores are ranked using two learned signals from your likes and dislikes:

  • Content similarity — themes, genres, and writing style (TF-IDF features)
  • Collaborative filtering — matrix factorization over reader/book interactions

The model is trained on user feedback and retrained when preferences change. The percentage on each card is normalized for display so the best match in the list reads as 100%.
